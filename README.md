### Projects
* [Fracture Reborn](https://github.com/tang0226/fracture-reborn) (2026): a fully browser-based escape-time fractal viewer. Renders Mandelbrot, Burning ship, and Tricorn fractals. Features  This app is the third (or fourth?) redesign of the original [Fracture](https://github.com/tang0226/fracture) app that I started building back in October of 2022. After my many failed attempts at redesigning the frontend UI system, I used Claude Code to help me build a vanilla React clone and a kernel-generating fractal engine from the ground up, resulting in this project. The journey has taught me a lot about how React works under the hood.
* [Fracture](https://github.com/tang0226/fracture) (2022-2024) My original fractal viewer. Verbose, naive spaghetti code whose development taught me many engineering principles the hard way. Still provides some beautiful renders, though.
